# 2.2 Structured Logging & Error Monitoring

> **Status**: ⬜ Not Started  
> **Priority**: 🟠 Production  
> **Effort**: Medium  

---

## Current State

- ❌ All errors use `console.error()` / `console.warn()`
- ❌ No error aggregation or alerting
- ❌ No correlation IDs for tracing requests
- ❌ No structured event logging for financial operations

---

## What To Build

### Integration Options

| Provider | Free Tier | Best For |
|----------|-----------|----------|
| **Sentry** | 5K errors/mo | Error tracking + performance |
| **LogTail (Better Stack)** | 1GB/mo | Structured log search |
| **Axiom** | 500MB/day | Full-stack observability |

### Structured Events to Log
- Wallet deductions and credits
- Payment completions and failures
- Voucher generations and claims
- Admin login attempts (success/failure)
- Router connectivity changes
- Refund operations

### Correlation IDs
- Generate UUID per request in middleware
- Pass through all function calls
- Include in error reports and log entries

### Alerting Rules
- Failed payments > 5/hour
- Router connectivity loss
- Admin login failures > 3/hour
- Wallet balance anomalies
