# 2.7 Dark Mode

> **Status**: ✅ Complete  
> **Effort**: Medium  

---

## Current State

- ✅ 8 color palettes exist with dedicated dark mode variants
- ✅ Dark mode system-preference auto-detection via `prefers-color-scheme`
- ✅ Dynamic theme toggle supported in both user navigation (`SideDrawer`) and Super Admin (`SuperAdminPage`)
- ✅ CSS custom property design tokens in `app/globals.css` (`:root.dark`, `[data-theme="dark"]`)
- ✅ Persists user preference in `localStorage` under `asuk_theme_mode`
- ✅ Smooth transitions between dark and light modes (`transition: background-color 0.25s ease, color 0.25s ease`)

## What Was Built

1. **Global Design Tokens (`app/globals.css`)**:
   - High-contrast, accessibility-checked dark tokens:
     - `--bg: #0C0D12`, `--surface: #141620`, `--surface-raised: #1A1D29`, `--surface-hover: #222638`
     - `--card-dark: #1A1D29`, `--border: rgba(255, 255, 255, 0.08)`, `--border-subtle: rgba(255, 255, 255, 0.04)`
     - `--text-primary: #F3F4F6`, `--text-secondary: #9CA3AF`, `--text-muted: #6B7280`
   - Dark theme root class overrides and component surfaces.

2. **Branding Context Dark Palette Engine (`app/context/BrandingContext.js`)**:
   - Extended `THEME_PALETTES` with 8 dark theme variants: `violet`, `gold`, `bronze`, `royalblue`, `emerald`, `rose`, `slate`, `crimson`.
   - Dynamic mode states: `system` | `dark` | `light`.
   - Reactive `prefers-color-scheme` media query listener updating the active theme dynamically on OS theme switch.
   - `toggleMode()` and `setMode()` functions exposed via `useBranding()`.
   - `localStorage` persistence under `asuk_theme_mode`.

3. **UI Theme Toggles**:
   - **User App Drawer (`app/components/SideDrawer.js`)**: Integrated theme switch button in drawer footer displaying active state (`🌙 Dark Mode` / `☀️ Light Mode`).
   - **Super Admin Header (`app/super-admin/page.js`)**: Integrated quick-toggle button in `sa-header-right`.

## Acceptance Criteria

- [x] Dark mode auto-detects system preference
- [x] Manual toggle available in UI
- [x] All 8 palettes have dark variants
- [x] Preference persisted across sessions in `localStorage`
- [x] Smooth CSS transitions between themes
