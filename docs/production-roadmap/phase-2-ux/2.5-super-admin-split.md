## What To Build

### Split into 16 tab components:

```
app/super-admin/
├── page.js                    ← Shell (~2KB): layout, tab bar, lazy imports
├── components/
│   ├── DashboardTab.js        ← Overview stats, revenue charts
│   ├── PlansTab.js            ← Internet plan CRUD
│   ├── VouchersTab.js         ← Voucher management
│   ├── FallbackVouchersTab.js ← Offline voucher pool
│   ├── UsersTab.js            ← Customer management
│   ├── WalletsTab.js          ← Wallet oversight
│   ├── TransactionsTab.js     ← Transaction ledger
│   ├── FinanceTab.js          ← Revenue reports, exports
│   ├── AnalyticsTab.js        ← Charts and metrics
│   ├── RouterTab.js           ← MikroTik management
│   ├── BrandingTab.js         ← Theme, logo, app name
│   ├── PortalTab.js           ← Captive portal template
│   ├── SettingsTab.js         ← General settings
│   ├── NotificationsTab.js    ← Push to users
│   ├── ChangeHistoryTab.js    ← Audit trail
│   └── SecurityTab.js         ← Auth, sessions, permissions
```

### Lazy Loading with React.lazy:

```javascript
const DashboardTab = lazy(() => import('./components/DashboardTab'));
const PlansTab = lazy(() => import('./components/PlansTab'));
// ...

<Suspense fallback={<TabSkeleton />}>
  {activeTab === 'dashboard' && <DashboardTab />}
  {activeTab === 'plans' && <PlansTab />}
</Suspense>
```

### Expected Result:
- **Initial load**: ~20KB (shell + active tab)
- **Per tab**: ~18KB average on demand
- **Total saving**: ~280KB less on first load
