# 4.1 Reseller / Agent System

> **Status**: ⬜ Not Started | **Effort**: Large

## What To Build
- Reseller role in `profiles.role` (`admin → reseller → customer`)
- Reseller portal: buy bulk vouchers at wholesale price, sell at retail
- Commission tracking and payout system
- Each reseller gets unique referral link
- Admin manages resellers from Super Admin

## Schema Changes
```sql
ALTER TABLE profiles ADD COLUMN reseller_discount NUMERIC(5,2) DEFAULT 0;
CREATE TABLE reseller_commissions (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  reseller_id UUID REFERENCES profiles(id),
  voucher_id UUID REFERENCES vouchers(id),
  commission_amount NUMERIC(12,2),
  status TEXT DEFAULT 'pending',
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```
