# 4.3 Customer Support Ticketing

> **Status**: ⬜ Not Started | **Effort**: Medium

## What To Build
- `support_tickets` table with status workflow (open → in-progress → resolved)
- In-app ticket form with file attachment
- Admin ticket management in Super Admin dashboard
- Auto-create ticket on failed purchase with `tx_ref` pre-filled

## Schema Changes
```sql
CREATE TABLE support_tickets (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id UUID REFERENCES profiles(id),
  subject TEXT NOT NULL,
  description TEXT NOT NULL,
  status TEXT DEFAULT 'open', -- 'open', 'in_progress', 'resolved', 'closed'
  priority TEXT DEFAULT 'medium',
  tx_ref TEXT,
  attachments JSONB DEFAULT '[]',
  admin_notes TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
```
