# 4.6 Wallet-to-Wallet Transfers

> **Status**: ⬜ Not Started | **Effort**: Medium

## What To Build
- Transfer form: recipient email/phone + amount
- Atomic dual-wallet RPC (deduct sender, credit receiver in single transaction)
- Transfer history in transaction ledger
- Transfer limits configurable by admin

## Schema Changes
```sql
-- New transaction type: 'wallet_transfer'
-- New RPC function for atomic transfer
CREATE OR REPLACE FUNCTION transfer_wallet_balance(
  p_sender_id UUID, p_receiver_id UUID, p_amount NUMERIC
) RETURNS BOOLEAN LANGUAGE plpgsql SECURITY DEFINER AS $$
BEGIN
  -- Deduct from sender
  UPDATE wallets SET balance = balance - p_amount WHERE user_id = p_sender_id AND balance >= p_amount;
  IF NOT FOUND THEN RETURN FALSE; END IF;
  -- Credit receiver
  UPDATE wallets SET balance = balance + p_amount WHERE user_id = p_receiver_id;
  IF NOT FOUND THEN
    -- Rollback sender deduction
    UPDATE wallets SET balance = balance + p_amount WHERE user_id = p_sender_id;
    RETURN FALSE;
  END IF;
  RETURN TRUE;
END; $$;
```
