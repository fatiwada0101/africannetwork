## What To Build
- **Centralized Session Accounting**: Track remaining voucher time and data across all routers centrally.
- **Smart Roaming**: Users purchase vouchers at Location A and seamlessly continue at Location B or C with remaining balance intact.
- **GPS Location Management**: Admin assigns router locations with GPS coordinates and coverage radius (Google Maps / Mapbox).
- **Multi-Signal Resolution**: Deterministic router identity injection (`?router=$(identity)`) + HTML5 GPS browser geolocation + subnet matching.
- **Fleet Management**: Monitor health, traffic, and connected users across all routers in real time.

## Acceptance Criteria
- [ ] Multiple routers and physical locations manageable from Super Admin
- [ ] Interactive GPS map with geofencing coverage radius
- [ ] Vouchers roam seamlessly between routers with accurate remaining time
- [ ] Anti-sharing concurrency locks prevent duplicate simultaneous usage
- [ ] Works with both Direct REST and behind-NAT Polling routers
