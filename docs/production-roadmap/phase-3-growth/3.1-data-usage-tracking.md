# 3.1 Data Usage Tracking & Bandwidth Dashboard

> **Status**: ⬜ Not Started | **Effort**: Medium

## What To Build
- Periodic sync of MikroTik hotspot user `bytes-in`/`bytes-out` to Supabase
- User-facing gauge/progress bar: `2.3 GB / 5 GB used`
- Low-data warning notification at 80% usage
- Integration with `/api/vouchers/status` endpoint

## Schema Changes
```sql
-- New columns on vouchers table or new usage_tracking table
ALTER TABLE vouchers ADD COLUMN bytes_used BIGINT DEFAULT 0;
ALTER TABLE vouchers ADD COLUMN bytes_limit BIGINT;
```

## Acceptance Criteria
- [ ] Real-time data usage visible to users
- [ ] Progress bar on home page
- [ ] 80% usage warning notification
